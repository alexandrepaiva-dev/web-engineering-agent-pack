# React Engineering
1. Inspect component/state conventions.
2. Keep state minimal and local.
3. Derive values during render where possible.
4. Use effects only for external synchronization.
5. Split components for responsibility/reuse, not line count.
6. Preserve stable keys and predictable form behavior.
7. Profile before adding memoization.
