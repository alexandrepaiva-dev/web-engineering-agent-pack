# Web Frontend Engineering

1. Inspect the existing design system, templates/components, CSS strategy, and browser support.
2. Identify semantic structure and interaction states.
3. Implement accessible markup before framework-specific abstractions.
4. Design responsiveness from content needs.
5. Cover relevant loading, empty, error, disabled, and permission states.
6. Validate keyboard behavior, labels, focus, contrast, and overflow.

Use framework-specific skills only when the project actually uses them.
