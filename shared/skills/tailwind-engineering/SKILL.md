# Tailwind CSS Engineering
Inspect the installed Tailwind version and existing token/component conventions.

- reuse existing CSS variables/theme tokens
- avoid a second token system
- use arbitrary values only for intentional one-offs
- move repeated patterns into reusable variants/components
- choose breakpoints from content needs
- follow existing dark-mode and formatting conventions
