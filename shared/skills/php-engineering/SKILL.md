# PHP Engineering
Inspect `composer.json`, PHP platform requirements, coding standards, static-analysis config, and tests.

- use precise PHP types compatible with the supported runtime
- prefer explicit constructor-injected dependencies
- follow existing PSR/project standards
- keep Composer constraints intentional
- avoid unrelated dependency upgrades
- use static analysis/tests as enforcement
