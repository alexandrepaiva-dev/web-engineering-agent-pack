# Node.js Engineering
1. Identify runtime model: server, serverless, worker, cron, CLI, or container.
2. Inspect Node version/runtime constraints.
3. Manage connections/resources according to lifecycle.
4. Avoid blocking CPU-heavy work on the event loop.
5. Handle shutdown/signals for long-lived processes.
6. Use backend/framework skills for higher-level behavior.
