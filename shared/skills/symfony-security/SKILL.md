# Symfony Security
Use `auth-security` for generic identity/access principles.

1. Inspect security configuration and installed Symfony version.
2. Understand firewall boundaries/authenticators.
3. Trace user provider/loading behavior.
4. Enforce object authorization with voters/project policy.
5. Review password hashing, sessions, and remember-me.
6. Test anonymous, authenticated, unauthorized, ownership, and role transitions.
