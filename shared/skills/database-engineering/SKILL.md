# Relational Database Engineering

1. Define entity identity, ownership, relationships, nullability, and uniqueness.
2. Encode durable invariants with database constraints where appropriate.
3. Identify real read/write query shapes.
4. Define transaction/concurrency behavior.
5. Design indexes from access patterns.
6. Plan safe schema rollout/backfill.
7. Use ORM/vendor-specific skills for concrete syntax and engine behavior.
