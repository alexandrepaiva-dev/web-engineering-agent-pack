# Project template

This file is retained for manual copying.

For profile-aware initialization, prefer:

```bash
weap project install --profile nextjs --project-dir /path/to/repo --init-project
```

or:

```bash
weap project install --profile symfony --project-dir /path/to/repo --init-project
```

The installer composes `AGENTS.base.md` with the selected stack snippet.
